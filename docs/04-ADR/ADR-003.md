ADR-003 — Follow FullStackHero Module Conventions

## Status

Accepted

## Context

MarketIntelligence must remain consistent with existing modules such as Catalog.

## Decision

Existing FSH module conventions take priority over introducing new internal architectural layers without a strong technical reason.

## Consequences

MarketIntelligence will follow the established patterns for:

- Domain
- Data
- Features
- Contracts
- Module registration
