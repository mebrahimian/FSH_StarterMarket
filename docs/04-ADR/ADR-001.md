# ADR-001 — Use FullStackHero as the Foundation

## Status

Accepted

## Context

The project requires a scalable modular architecture with authentication, authorization, multi-tenancy and infrastructure already available.

## Decision

FSH.MarketIntelligence will be implemented as a native module inside the FullStackHero architecture.

## Consequences

Positive:

- Existing infrastructure can be reused.
- Authentication and authorization are available.
- The module follows established conventions.
- Future SaaS capabilities can build on the existing platform.

Negative:

- The module must follow FSH conventions.
- Some architectural decisions are constrained by the framework.
