# ADR-002 — Use a Modular Monolith Architecture

## Status

Accepted

## Context

The project requires multiple business capabilities but does not initially require independent microservices.

## Decision

MarketIntelligence will be implemented as a module inside a modular monolith.

## Consequences

Positive:

- Lower operational complexity.
- Easier development.
- Shared infrastructure.
- Clear module boundaries.

Future migration to distributed services remains possible if required.
