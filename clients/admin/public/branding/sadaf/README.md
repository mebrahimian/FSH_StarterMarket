# Sadaf logo package — v2

این بسته شامل نسخهٔ نهایی و تأییدشدهٔ نشان «صدف» است.

## Files

- `sadaf-mark-primary.svg` — نسخهٔ اصلی رنگی با پس‌زمینهٔ شفاف؛ انتخاب اول برای وب و رابط کاربری
- `sadaf-mark-primary-1024.png` — خروجی PNG بزرگ و شفاف
- `sadaf-mark-dark.svg` — نسخهٔ مخصوص پس‌زمینهٔ تیره
- `sadaf-mark-dark-1024.png` — خروجی PNG نسخهٔ تیره با پس‌زمینهٔ شفاف
- `sadaf-mark-monochrome.svg` — نسخهٔ تک‌رنگ برای چاپ، مهر و کاربردهای محدود رنگ
- `sadaf-mark-monochrome-1024.png` — خروجی PNG تک‌رنگ و شفاف
- `sadaf-favicon.svg` — فاوآیکن برداری
- `sadaf-favicon-256.png` — فاوآیکن PNG با اندازهٔ ۲۵۶ پیکسل
- `sadaf-favicon-32.png` — فاوآیکن PNG با اندازهٔ ۳۲ پیکسل
- `sadaf-favicon-16.png` — فاوآیکن PNG با اندازهٔ ۱۶ پیکسل
- `sadaf-favicon.ico` — فاوآیکن سازگار با مرورگرها

## Recommended usage

- در Dashboard از `sadaf-mark-primary.svg` استفاده شود.
- روی پس‌زمینه‌های خیلی تیره از `sadaf-mark-dark.svg` استفاده شود.
- برای favicon، ابتدا `sadaf-favicon.svg` و سپس `sadaf-favicon.ico` به‌عنوان fallback معرفی شود.
- نسبت تصویر و فاصلهٔ داخلی نشان تغییر نکند.
